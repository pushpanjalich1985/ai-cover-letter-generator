# AI Internship Cover Letter Generator

## Problem

Students often spend hours rewriting similar cover letters for different internship applications, which is repetitive and time-consuming.

## Solution

Built an AI-powered automation workflow that generates personalized cover letters based on company details, job title, job description, and internship links automatically.

## Workflow

Webhook → Make.com → Gemini AI → Cover Letter Generation → Notion

## What it does

* Collects internship details through a custom form
* Accepts company name, role, job description, and application link
* Uses Gemini AI to generate personalized cover letters
* Stores generated applications in Notion
* Reduces repetitive application work

## Input Fields

* Company Name
* Job Title
* Internship Link
* Job Description
* Skills
* Education

## Tech Stack

* Make.com
* Webhooks
* Gemini AI
* Notion

## Features

* Personalized cover letter generation
* Role-specific content adaptation
* AI-powered writing
* Centralized application storage
* No-code automation
